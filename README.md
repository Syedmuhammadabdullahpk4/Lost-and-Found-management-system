Lost and Found Management System

A menu-driven Lost and Found Management System developed using the C programming language as a Computer Programming course project at NED University of Engineering & Technology.

Project Overview

This application is designed to manage information about lost and found items in an organized way. Users can register item details, display records, and search for items.

Implemented Features

- Add new lost or found item records
- Automatically generate unique item IDs
- Display all registered records
- Search records by item ID
- Search records by item name
- Basic input validation

Technologies Used

- Programming Language: C
- IDE: Visual Studio Code
- Compiler: GCC
- Version Control: Git and GitHub

Concepts Applied

- Structures
- Arrays
- Functions
- Pointers
- Strings
- Loops
- Conditional statements
- Switch-case

Future Improvements

- Update existing records
- Delete records
- Generate summary reports
- Save and load records using file handling
